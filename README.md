# 포모리 — 25분 집중 타이머

> 집중과 휴식을 25분 단위로 끊어가는 포모도로 타이머.
> 작업 큐, 풀스크린 포커스 모드, 다크 모드, 모바일 전용 UI를 지원합니다.

## 데모

[포모리 보러가기](https://pomori.kr)

## 주요 기능

### 타이머
- **자유로운 시간 조정** — 집중 1~60분, 휴식 0~10분 사이 자유 설정
- **부드러운 진행 링** — `requestAnimationFrame` 기반 60fps DOM 직접 업데이트, 일시정지 시 즉시 스냅
- **시계형 / 디지털형** — 원하는 표시 방식 선택, 마지막 10초는 카운트다운 강조 색
- **풀스크린 포커스 모드** — 시계만 크게 띄워 다른 UI 거슬림 없이 몰입 (`ESC` 종료)
- **백그라운드 자동 정지** — 탭이 백그라운드면 tick 자체가 멈춰 배터리/CPU 낭비 없음
- **자동 시작** — 휴식 후 다음 세션을 자동으로 이어서 시작 (옵션)

### 작업 큐
- **드래그 앤 드롭 정렬** — 데스크탑에서 자유롭게 순서 변경
- **현재 작업 표시** — 진행중·일시정지·대기 상태 뱃지
- **휴식 중 다음 작업 미리보기** — 휴식 시간 동안 다음 작업이 "대기" 상태로 표시
- **삭제 + 되돌리기** — 토스트의 "되돌리기" 버튼으로 즉시 복구
- **모두 삭제** — 한 번에 큐 비우기 (확인 모달 + 되돌리기 지원)
- **현재 작업도 삭제** — 진행 중일 땐 확인 모달, 큐의 다음 작업이 자동 승격

### 모바일
- **헤더 두 줄 레이아웃** — 좁은 화면에서 제목/액션 영역 분리
- **현재 작업 카드** — 시계 위에 진행중/대기 상태와 함께 표시, 탭하면 큐 모달
- **모바일 전용 큐 모달** — 큰 터치 타겟(60px 행), 하단 고정 입력바 + safe-area 인셋
- **fluid 사이즈** — 320px까지 깨짐 없음, `clamp()` 기반 폰트/시계

### 인터페이스
- **다크 모드 + 4가지 컬러 테마** — 블루, 그린, 인디고, 앰버 (눈 피로/집중 특성에 맞춰)
- **세련된 토스트** — 중복 자동 방지, 되돌리기 지원, 부드러운 페이드/슬라이드
- **아이콘 버튼 툴팁** — 마우스 호버 시 부드럽게 등장 (CSS-only)
- **세션 완료 애니메이션** — 작업 완료 시 체크 마크 펄스
- **브라우저 알림** — 세션·휴식 종료 시 데스크탑 알림 (HTTPS 필요)

### 데이터
- **오늘의 기록** — 완료한 세션 수와 작업 목록 자동 집계, 자정마다 리셋
- **로컬 저장** — `localStorage` 영속화, 별도 서버/계정 없음
- **새로고침 보정** — 페이지 복귀 시 경과 시간 자동 반영

## 기술 스택

- **React 18** + **TypeScript**
- **Vite** — 빌드 / 개발 서버
- **Zustand** + persist — 상태 관리 + localStorage 영속화
- **@dnd-kit** — 작업 큐 드래그 앤 드롭
- **CSS Modules** — 스타일링
- **Pretendard** — 본문 글꼴

## 빠르게 실행하기

```bash
git clone https://github.com/susung1107/Pomori-timer.git
cd Pomori-timer
npm install
npm run dev
```

기본 포트는 `http://localhost:5173`.

## 빌드

```bash
npm run build       # tsc + vite build → dist/ 생성
npm run preview     # 빌드된 결과를 로컬에서 미리보기
```

## 키보드 / 인터랙션

- 풀스크린 모드 종료: `ESC`
- 작업 제목 편집: 작업 카드 탭 → 입력 → `Enter` 저장 / `ESC` 취소
- 작업 큐 정렬: 드래그 앤 드롭 (드래그 핸들 또는 행 자체)
- 모바일 작업 큐: 시계 위 카드 탭 → 전체화면 모달

## 성능 최적화

- 진행 링: `requestAnimationFrame` 60fps DOM 직접 업데이트 (React 리렌더와 분리)
- 시계 텍스트: rAF로 표시 초가 바뀌는 정확한 순간만 React 리렌더 (≈1Hz)
- 백그라운드 탭: rAF 자동 정지
- `React.memo` + `useCallback` — 무관한 리렌더 차단
- `document.title` 갱신: 자체 1초 interval, 동일 값 가드

## 브라우저 호환

- Chrome / Edge / Safari / Firefox 최신 버전
- 모바일: iOS Safari, Android Chrome
- 알림은 HTTPS 환경에서만 동작 (배포 후엔 자동 적용)
